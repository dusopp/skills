While working on this, which important decisions / choices did you make that you are
not confident about?

Think about this deeply, reason about all the important decisions made, and think
whether these decisions have any other great alternatives that have not been considered.

Do NOT list the choices / decisions where the best possible solution was already used.

Only list the decisions that are genuinely uncertain.

Answer in short, in plain English. Be very concise.
